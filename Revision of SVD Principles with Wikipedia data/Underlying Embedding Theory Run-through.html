# Creating function to collect text from random wikipedia pages
get.wiki.corpus <-
function(documents){
  i = 1

  output <- tibble()

  while (i <= documents) {
    page = read_html("https://en.wikipedia.org/wiki/Special:Random")

    title = page %>%
      html_nodes("h1") %>%
      html_text %>%
      paste0(collapse = "|")

    text <-
    page %>%
      html_nodes("p") %>%
      html_text %>%
      paste0(collapse = ". ")

    output <- output %>%
      bind_rows(
        tibble(
          title = title,
          text = text 
        )
      )
    
    i = i + 1

  }
  
  return(output)
}

Mathematical Background and Computation

The mathematical methodlogy being used is Singular Vaue Decomposition, which is essentially a way to factorize or break down a matrix into three matrixes. The formula is given below:

\[ A = U \Sigma V^T \]

Manually breaking them down would required finding the eigen values for $ AA^T $ in the case of $ U $ (left singular matrix) or $ A^TA $ in the case of $ V $ (right singular matrix). Luckily, base R gives us a method for tackling this:

# Declare number of dimensions to be trained for
dimension_num <- 400

# Use base function to perform Singular Value Decomposition
wiki.svd <- svd(wiki.sparse, nu = dimension_num, nv = dimension_num)

The explaination for the results of Singular Value Decomposition is pretty straight forward. The multiplication of $ U$ gives rise to the projection of the documents into the feature space. This could be used directly for prediction. On the other hand, $ V$ are the individual word embeddings in the same feature space. They can be used to break down a sentence into its document embedding.

Before we continue, lets make a function that calculates the cosine of the angle between two vectors. Angles that are close to each other would have values closer to 1, other angles with values closer to -1 show great dismilarity and 0 can be infered as being neutral.

cosine_similarity <- function(token, data, target_variable = "document"){
  data_matrix = as.matrix(data %>% select_if(!str_detect(colnames(.), target_variable)))

  rownames(data_matrix) = data[[target_variable]]
  colnames(data_matrix) = paste0("dim_", 1:ncol(data_matrix))

  token_matrix = matrix(data_matrix[rownames(data_matrix) == token,], nrow = 1)[rep(1, nrow(data_matrix)),]

  result = rowSums(data_matrix * token_matrix) / (sqrt(rowSums(data_matrix ^ 2)) * (sqrt(rowSums(token_matrix ^ 2))))

  output = tibble(
    document = names(result),
    cosine = result
  )

  return(output)

}
